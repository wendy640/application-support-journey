# 📅 Day 22 – SQL Text Functions

## Topics Covered

- UPPER()
- LOWER()
- LENGTH()
- TRIM()
- CONCAT()
- REPLACE()
- SUBSTRING()
- Combining/nesting functions

## What I Learned

Today I started learning SQL Functions with a focus on text/string manipulation.

### UPPER()
Converts text to uppercase.

### LOWER()
Converts text to lowercase.

### LENGTH()
Returns the number of characters in a string.

### TRIM()
Removes unnecessary spaces from the beginning and end of text.

### CONCAT()
Combines multiple values into one string.

### REPLACE()
Replaces part of a string with another value.

### SUBSTRING()
Extracts a specific section of a string.

## Key Takeaway

SQL functions can be used not only to retrieve data but also to clean, transform, and format it.

I also learned that functions can be nested, for example:

UPPER(TRIM(employee_name))

## Why It Matters

Text functions are useful when troubleshooting data-quality issues, standardizing information, and preparing data for reports.
