# 📅 Day 11 – GROUP BY in PostgreSQL

Today, I learned how to summarize data using the `GROUP BY` clause in PostgreSQL.

Instead of viewing individual records, `GROUP BY` allows related rows to be grouped together so that aggregate functions can calculate meaningful summaries for each group.

---

## 📚 Topics Covered

- `GROUP BY`
- Grouping by a single column
- Grouping by multiple columns
- `COUNT()`
- `SUM()`
- `AVG()`
- `MIN()`
- `MAX()`
- `ORDER BY` with grouped results

---

## 🎯 Key Takeaways

- Learned how `GROUP BY` organizes rows into meaningful groups.
- Used aggregate functions to summarize grouped data.
- Grouped data by one column and by multiple columns.
- Built reports that answered real business questions instead of displaying raw records.
- Practiced combining `GROUP BY` with `ORDER BY` to improve report readability.

## 🧠 Reflection

Today's lesson helped me understand the relationship between aggregate functions and `GROUP BY`.

Aggregate functions calculate values, while `GROUP BY` determines how those calculations are organized.

For example, instead of calculating one average price for all products, I can now calculate the average price for each product category.

This is a common requirement in reporting, analytics, and Application Support.
