# 📅 Day 12 – HAVING, WHERE vs HAVING, and CASE in PostgreSQL

Today, I learned how to filter grouped results using the `HAVING` clause and explored how it differs from `WHERE`. I also had my first introduction to using `CASE` expressions to categorize data and `EXTRACT()` for grouping by date parts.

---

## 📚 Topics Covered

- `HAVING`
- `WHERE` vs `HAVING`
- SQL Query Execution Order
- `GROUP BY` with Expressions
- `EXTRACT()`
- `CASE WHEN`

---

## 🎯 Key Takeaways

- Learned that `WHERE` filters rows before grouping.
- Learned that `HAVING` filters groups after aggregation.
- Explored SQL's logical query execution order.
- Used expressions with `GROUP BY` for more flexible reporting.
- Learned how `CASE` can transform raw values into meaningful categories.
- Began writing more business-oriented SQL reports.
