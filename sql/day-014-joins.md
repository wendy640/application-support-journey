## 🧠 Reflection

Today's lesson helped me realize that JOINs are not just about SQL syntax—they're about understanding how data is related.

A simple three-question approach made the concept much clearer:

1. What information do I need?
2. Which table contains it?
3. How are the tables connected?

This mindset will help me write better SQL queries and troubleshoot data-related issues more effectively.
